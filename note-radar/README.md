# note売れ筋レーダー

直近24時間に公開された **有料note** を集めて、スキの伸び方から「いま売れていそうな順」に並べるツールです。

## できること
- キーワード・作者・#ハッシュタグで検索
- 公開からの時間（3h / 6h / 12h / 24h）、価格帯、ジャンル、最低スキ数で絞り込み
- 並べ替え: 勢いスコア / 直近3時間のスキ増加 / 1時間あたりスキ / スキ数 / スキ×価格 / 価格 / 新着
- カード表示・表表示の切り替え、CSV出力、検索条件のURLコピー
- ○で保存、✕で非表示（ブラウザ内に保存）
- サイドの集計: ジャンル別の勢い、急上昇ハッシュタグ、価格帯の分布、公開時間帯、注目クリエイター
- noteごとの詳細（スキの推移グラフ、売上の目安）

## 「売れてる」の判定について
note.com は販売数を公開していません。そのため、有料noteに付く **スキの数と増えるスピード** を売れ行きの代わりの指標にしています。

- 勢いスコア = (1時間あたりのスキ × 0.6 + 直近3時間のスキ増加ペース × 0.4) × (1 + 価格/10000、上限3) × 10
- 直近の増加量は、1時間ごとに保存しているスキ数の履歴（`data/history.json`）から計算します

## 仕組み
```
GitHub Actions（毎時） → scripts/fetch_notes.py → data/latest.json → GitHub Pages の画面
```
ブラウザから直接 note.com のデータは取れない（CORS の制限）ため、GitHub Actions がデータを集めて JSON にしています。
データがまだ無いうちは、画面に **サンプルデータ** が表示されます。

## 公開手順
1. このブランチをデフォルトブランチにマージする（定期実行はデフォルトブランチでしか動かないため）
2. GitHub の **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
3. **Actions → note-radar → Run workflow** で1回手動実行する
4. 以降は毎時自動でデータが更新され、`https://<ユーザー名>.github.io/<リポジトリ名>/` で見られます

## ローカルで試す
```bash
python3 note-radar/scripts/fetch_notes.py --pages 1 --keywords "副業,ChatGPT"
cd note-radar && python3 -m http.server 8000
```

## 注意
- note.com の非公式APIを使っています。仕様が変わると取得できなくなる可能性があります。そうなりにくいよう、レスポンスの形に頼らずnoteのデータを探す作りにしています。
- アクセスは1秒に1回程度に抑えています。収集するキーワードは `fetch_notes.py` の `DEFAULT_KEYWORDS` で変更できます。
