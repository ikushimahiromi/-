# note 売れ筋リサーチ

キーワードやクリエイターIDから note の記事を集めて、売れていそうな有料noteを探すローカルアプリです。依存パッケージはありません（Node.js 18 以上だけで動きます）。

## 使い方

```bash
cd note-research
npm start          # http://localhost:3000 を開く
npm run demo       # ネットに繋がずダミーデータで画面を試す
```

## できること

- **ジャンル検索**: 副業・投資・AI・恋愛・美容・競馬予想など15ジャンルからワンクリックで売れ筋を調査（各ジャンルは3つの検索キーワードをまとめて検索）
- **ランキング**: 全ジャンルの有料記事を集めて、次の3つを作成（集計期間と、推定売上／スキ数／勢いの基準を切り替え可）
  - ジャンル別ランキング（どのジャンルが売れているか。クリックでそのジャンルを検索）
  - 売れ筋note TOP30（ジャンルで絞り込み可）
  - 売れ筋クリエイター TOP10
- **キーワード検索**: 「副業, ChatGPT」のようにカンマ区切りで複数キーワードをまとめて調査
- **クリエイター分析**: `note.com/xxxx` の `xxxx` を入れると、その人の記事一覧を分析
- **絞り込み**: 有料のみ・価格帯・最低スキ数・公開期間
- **並び替え**: 推定売上 / スキ数 / 勢い（スキ/日）/ 価格 / 新着
- **集計**: 有料記事の割合、中央価格、価格帯別の記事数と平均スキ、よく使われるハッシュタグ、売れているクリエイター
- **CSV出力**: Excel でそのまま開ける形式（BOM付き UTF-8）

## 総合スコア（0〜100点）

「売れているか」を1つの指標でなく、次の4つを組み合わせて判断します。配分は画面の「総合スコアの配分」で変えられます。

| 指標 | 中身 | 初期配分 |
|---|---|---|
| 累計スキ | 記事についたスキの合計 | 35 |
| 直近の伸び | 直近7日間に増えたスキ（1日あたり） | 35 |
| 反応率 | フォロワー数に対するスキの割合 | 15 |
| 価格 | 同じスキ数なら高い記事ほど売上が大きい | 15 |

各指標を「集めた記事の中で上位何%か」に直して、配分どおりに合算します。

- **直近の伸び**: note は「いつスキされたか」を公開していないため、アプリが記事を取得するたびにスキ数を `data/snapshots.json` に記録し、約7日前の記録との差を出します。2回目以降の取得から表示され、毎日使うほど正確になります（記録が無い記事は「公開からのスキ/日」で代用）。
- **閲覧数（PV）**: note では著者本人しか見られないため取得できません。代わりに反応率を使っています。

## 推定売上の考え方

note は購入数を公開していないため、**価格 × スキ数 × 購入率係数** で目安を出しています。係数は画面で変更できます（初期値 1 = スキ1件につき1件売れたと仮定）。あくまで相対比較のための指標です。

ジャンルと検索キーワードは `server.js` の `GENRES` で自由に追加・変更できます。

## 注意

- ランキング作成は全ジャンル（15ジャンル × 3キーワード）を取得するため、初回は1分ほどかかります（2回目以降の10分間はキャッシュで即表示）。

- note.com の公式に公開されていない API を使っています。仕様変更で動かなくなる可能性があります。
- note への負荷を避けるため、リクエストは 1 秒に 1 回、1 キーワードあたり最大 200 件に制限し、結果は 10 分間キャッシュします。
- 取得したデータは個人のリサーチ用途にとどめ、note の利用規約に従ってください。
